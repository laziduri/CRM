# Bank Knowledge Base

Place official bank information here as Markdown files. **ONLY** include content from official bank websites.

## Allowed Sources

- dbs.com
- posb.com.sg
- ocbc.com
- uob.com.sg
- maybank2u.com.sg (or maybank.com.sg)
- cimb.com.sg
- hsbc.com.sg
- standardchartered.com.sg
- rhbgroup.com

## Format

```markdown
---
title: Bank Product Name
source: https://official-bank-domain.com/product-page
---

# Product Information

Content from official bank website...

Source: https://official-bank-domain.com/product-page
```

## Example

Create a file like `dbs-personal-loan.md`:

```markdown
---
title: DBS Personal Loan
source: https://www.dbs.com.sg/personal/loans/personal-loans
---

# DBS Personal Loan

DBS Personal Loan offers competitive interest rates starting from 3.88% p.a. (EIR from 7.56% p.a.).

Loan amounts: Up to 10 times your monthly income or $300,000, whichever is lower.

Source: https://www.dbs.com.sg/personal/loans/personal-loans
```

## Important

- Only include publicly available information from official bank websites
- Always include the source URL
- Keep content factual and avoid marketing language
- Update content regularly as bank terms change
